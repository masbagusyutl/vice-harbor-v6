Vice Harbor is a 3D open-world crime game set in a sun-soaked harbor city: drive and steal cars, run 7 story jobs and 3 street races, work taxi fares, hunt 24 hidden harbor tokens, claim turf, build a 3-person crew, and outrun a wanted level that brings roadblocks and a police helicopter — all rendered with a hand-rolled WebGL engine, golden-hour light, wet neon streets, and a live minimap HUD.

## Run it

```sh
node serve.ts
```
